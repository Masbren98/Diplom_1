Дипломный проект. Задание 1: Юнит-тесты

Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers


Созданы юнит-тесты, покрывающие классы `Bun`, `Burger`, `Ingredient`, `Database`

Процент покрытия более 70% (отчет: `htmlcov/index.html`)

Структура проекта

1)`praktikum` - пакет, содержащий код программы
2)`tests` - пакет, содержащий тесты, разделенные по классам:
2.1) `test_bun.py` 
2.2) `test_ingredient.py` 
2.3) `test_burger.py` 
2.4) `test_database.py` 
3) `htmlcov` - пакет, содержащий отчет о проценте покрытия
4) conftest.py - фикстуры для тестов
5) data.py - входные данные для тестов
